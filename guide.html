01앱 개요

"오늘 뭐 하지?"를 없애는 것이 목표입니다. 요일별로 할 운동을 미리 정해두고, 각 운동에 시범 영상을 붙여두면 운동할 때 항목만 누르면 바로 영상이 재생됩니다.

루틴 여러 개
‘상체 위주’, ‘출장용’처럼 루틴을 여러 벌 만들어 상단 탭으로 전환합니다.
요일별 구성
월~일 각각에 운동 목록을 둡니다. 오늘 요일은 자동으로 강조되고 펼쳐집니다.
영상 연결
운동 하나당 영상 하나. 폰 안의 파일이나 유튜브 링크 중 원하는 쪽을 고릅니다.
완료 기록
영상을 끝까지 보거나 [완료]를 누르면 오늘 기록에 남고, 연속 달성 일수가 집계됩니다.
완전 로컬
계정·로그인·서버가 없습니다. 모든 데이터는 기기의 브라우저 저장소에만 있습니다.
오프라인
서비스 워커가 앱 자체를 캐시하므로 인터넷 없이도 켜집니다. (유튜브 영상은 예외 — 인터넷 필요)

02설치와 시작

브라우저 탭에서 그냥 써도 되지만, 홈 화면에 추가하면 주소창 없는 전체 화면으로 열리고 저장 데이터도 더 안전하게 보존됩니다.

아이폰 (Safari)

  1. Safari로 앱 주소를 엽니다. Safari여야 합니다 — 크롬 등 다른 앱에서는 홈 화면 추가가 되지 않습니다.
  2. 하단 공유 버튼(↑) → 홈 화면에 추가를 누릅니다.
  3. 홈 화면에 생긴 아이콘으로 실행합니다.

안드로이드 (Chrome)

  1. Chrome으로 앱 주소를 엽니다.
  2. 우측 상단 ⋮ → 앱 설치 또는 홈 화면에 추가를 누릅니다.
  3. 설치 배너가 뜨면 그것을 눌러도 됩니다.
https에서만 동작합니다 서비스 워커·파일 접근·저장소 API가 모두 보안 컨텍스트를 요구합니다. http:// 주소로 열면 기능이 동작하지 않습니다. (localhost는 예외)

03화면 구성

하단 탭 3개와 상단 메뉴 하나가 전부입니다.

루틴
메인 화면. 상단에 주간 요약(요일별 연결됨/전체)이 있고, 아래로 월~일 접이식 목록이 이어집니다. 오늘 요일에는 ‘오늘’ 배지가 붙고 완료 개수가 표시됩니다.
기록
연속 달성 일수, 누적 완료 횟수, 오늘 완료 횟수와 최근 3주 달성 현황을 점으로 보여줍니다.
영상함
연결한 영상 전체 목록. 각 영상이 어느 루틴·요일에서 쓰이는지 표시되고, 저장공간 사용량도 여기서 확인·관리합니다.
상단 ☰ 메뉴
루틴 백업 내보내기 / 백업 불러오기 / 진단 정보 보기.

04기본 조작법

규칙은 하나입니다 — 짧게 누르면 실행, 길게 누르면 메뉴.

운동 짧게 누르기영상 재생. 아직 영상이 없으면 연결 방식 선택 창이 열립니다.
운동 길게 누르기재생 · 영상 변경 · 이름 변경 · 완료 표시 · 순서 이동 · 연결 해제 · 삭제 메뉴.
루틴 탭 누르기다른 탭이면 전환, 이미 선택된 탭을 다시 누르면 탭 메뉴가 열립니다.
요일 헤더 누르기해당 요일을 펼치거나 접습니다. 한 번에 한 요일만 펼쳐집니다.
PC에서 쓸 때 길게 누르기는 마우스를 누른 채 0.5초 정도 기다리면 됩니다. Esc 키로 재생 화면이나 열린 메뉴를 닫을 수 있습니다.

05루틴 · 운동 관리

루틴(탭)

추가
탭 줄 오른쪽 ＋ 버튼. 새 루틴은 요일마다 ‘운동 1’, ‘운동 2’ 두 칸이 기본으로 들어 있습니다.
이름 변경
탭 길게 누르기 → 이름 변경 (최대 40자)
복제
구성을 통째로 복사해 ‘◯◯ 복사본’을 만듭니다. 영상 연결도 함께 복사됩니다.
순서 이동
왼쪽 / 오른쪽으로 이동
삭제
루틴이 2개 이상일 때만 가능합니다. 삭제하면 그 루틴에서만 쓰이던 영상은 자동 정리됩니다.

운동 항목

기본 운동
루틴을 만들 때 생기는 ‘운동 1 / 운동 2’. 이름 변경은 되지만 삭제는 되지 않습니다.
추가 운동
요일을 펼친 뒤 ＋ 추가 운동으로 원하는 만큼 추가합니다. 삭제도 자유롭습니다.
이름 자동 입력
이름이 아직 ‘운동 1 / 운동 2’인 항목에 영상을 연결하면, 파일명(확장자 제외) 또는 유튜브 영상 제목이 이름으로 자동 입력됩니다.
순서 바꾸기
길게 누르기 → 위로 / 아래로 이동

06동영상 연결 — 2가지 방식

운동을 누르면 연결 방식 선택 창이 먼저 뜹니다. 항목마다 다른 방식을 섞어 써도 됩니다.

내 폰에서 파일 선택갤러리·파일 앱에 있는 동영상을 고릅니다. 오프라인에서도 재생됩니다.
유튜브 링크 붙여넣기링크만 넣으면 제목·썸네일을 자동으로 가져오고 앱 안에서 재생됩니다.
비교 항목폰에 있는 파일유튜브 링크
오프라인 재생가능불가 — 인터넷 필요
저장공간 사용기기에 따라 0 또는 영상 용량만큼거의 없음 (주소·썸네일만)
연결하기파일 선택 한 번링크 복사 → 붙여넣기
영상 길이 표시표시됨표시 안 됨 (‘유튜브 · 채널명’으로 표기)
썸네일영상에서 직접 캡처유튜브 공식 썸네일
백업에 포함미포함 (기기 밖으로 못 나감)포함 — 다른 기기에서도 복원됨
끊길 수 있는 경우원본 파일을 삭제·이동한 경우영상이 비공개/삭제되거나 외부 재생이 막힌 경우
광고없음유튜브 정책에 따라 재생됨

파일 연결이 저장되는 두 가지 방식

기기가 최신 파일 접근 기능(File System Access API)을 지원하는지에 따라 자동으로 갈립니다. 현재 내 기기가 어느 쪽인지는 영상함 → 저장공간 카드 맨 아래 문구와 진단 정보에서 확인할 수 있습니다.

원본 참조
파일을 복사하지 않고 원본을 가리킵니다. 저장공간을 쓰지 않는 대신, 원본을 지우거나 옮기면 연결이 끊깁니다. 재생할 때 기기가 접근 권한을 다시 물어볼 수 있습니다.
앱 저장소 복사
영상을 앱 저장소로 복사합니다. 원본을 지워도 재생되지만 용량을 그만큼 차지합니다. (아이폰 Safari가 주로 이 방식입니다)
연결 바꾸기 · 해제하기 운동을 길게 눌러 동영상 변경으로 다른 영상을 연결하거나, 연결 해제로 영상만 떼어낼 수 있습니다. 어느 운동에서도 쓰이지 않게 된 영상은 자동으로 정리되어 저장공간을 되돌려줍니다.

07유튜브 링크 자세히

붙여넣은 유튜브 영상은 앱 화면 안에서 그대로 재생됩니다. 유튜브 앱으로 튕겨나가지 않습니다.

연결하는 법

  1. 유튜브 앱에서 공유 → 링크 복사
  2. 내 루틴에서 운동을 누르고 유튜브 링크 붙여넣기 선택
  3. [붙여넣기] 버튼을 누르거나, 입력칸을 길게 눌러 직접 붙여넣기
  4. [연결] — 제목·채널·썸네일을 자동으로 가져옵니다

인식되는 주소 형식

youtu.be/VIDEOID youtube.com/watch?v=VIDEOID youtube.com/shorts/VIDEOID youtube.com/live/VIDEOID youtube.com/embed/VIDEOID m. / music. 도메인 영상 ID 11자만

재생목록·인덱스 같은 뒤에 붙는 값(&list=…, &index=…)은 무시하고 영상 하나만 정확히 골라냅니다. 유튜브 주소가 아니면 “유튜브 주소를 알아볼 수 없습니다”라고 알려주고 창이 닫히지 않으니 다시 붙여넣으면 됩니다.

시작 지점 지정

주소에 시간이 들어 있으면 그 지점부터 재생합니다. 준비 운동이 긴 영상에서 본론부터 보고 싶을 때 유용합니다.

?t=90 → 1분 30초부터 ?t=1m30s → 동일 ?t=1h2m3s → 1시간 2분 3초부터

유튜브 앱에서 공유할 때 “재생 시점부터 시작” 옵션을 켜면 이 값이 자동으로 들어갑니다.

같은 영상을 여러 운동에

이미 연결해 둔 유튜브 영상을 다른 운동에 또 연결하면 새로 만들지 않고 기존 항목을 공유합니다. 영상함에 중복이 쌓이지 않고, 어느 운동에서 쓰이는지 한 곳에 모여 보입니다.

재생이 안 되는 경우 업로더가 외부 사이트 재생(임베드)을 막아둔 영상, 비공개·삭제된 영상, 일부 연령 제한 영상은 앱 안에서 재생되지 않습니다. 이때는 안내 창과 함께 [유튜브에서 열기] 버튼이 뜨니 유튜브 앱에서 보시면 됩니다. 이 버튼은 항목을 길게 눌러도 항상 사용할 수 있습니다.
인터넷과 광고 유튜브 영상은 저장공간을 쓰지 않는 대신 재생할 때마다 데이터를 씁니다. 와이파이 없는 헬스장에서 자주 본다면 파일 연결이 낫습니다. 광고는 유튜브 정책상 그대로 나옵니다.

08재생과 완료 기록

전체 화면 재생
운동을 누르면 검은 배경의 전용 재생 화면이 열립니다. 상단에 운동 이름, 하단에 [건너뛰기] · [완료] 버튼이 있습니다.
화면 꺼짐 방지
재생 중에는 화면이 자동으로 꺼지지 않습니다. 앱을 잠깐 벗어났다 돌아와도 다시 걸립니다.
자동 완료
영상이 끝까지 재생되면 파일·유튜브 모두 오늘 완료로 자동 표시됩니다.
수동 완료
하단 [완료] 버튼, 또는 항목을 길게 눌러 ‘오늘 완료로 표시’. 같은 방법으로 취소도 됩니다.
닫기
우측 상단 ✕, 하단 [건너뛰기], 또는 Esc 키.

기록 탭에서 보이는 것

  • 연속 달성 — 오늘부터 거슬러 올라가며 완료가 하나라도 있는 날이 며칠 이어졌는지
  • 누적 완료 — 전체 기간 동안 완료한 운동 횟수의 합계
  • 최근 3주 — 날짜별 완료 개수를 점으로 표시

완료 기록은 날짜별로 저장되며, 자정이 지나면 새 날로 넘어갑니다.

09영상함과 저장공간

영상 목록
연결한 순서(최신순)로 전부 보여줍니다. 각 항목에 썸네일, 이름, 길이 또는 ‘유튜브 · 채널명’, 그리고 어느 루틴 · 요일에서 쓰이는지가 표시됩니다.
영상 삭제
휴지통 버튼으로 지우면 그 영상을 쓰던 모든 운동의 연결이 함께 해제됩니다. (폰의 원본 파일은 지워지지 않습니다)
사용량 확인
맨 위 카드에서 앱이 차지하는 용량과 브라우저가 허용한 최대치를 막대로 보여줍니다.
자동 삭제 방지
브라우저는 저장공간이 부족하면 앱 데이터를 임의로 지울 수 있습니다. [자동 삭제 방지 켜기]로 이를 막아두세요. 홈 화면에 추가한 상태에서 더 잘 허용됩니다.
용량이 부족하다는 안내가 뜬다면 영상함에서 더 이상 쓰지 않는 영상을 지우거나, 큰 파일을 유튜브 링크로 바꿔 연결해 보세요. 유튜브 링크는 저장공간을 거의 쓰지 않습니다.

10백업과 복원

상단 ☰ 메뉴에서 루틴 구성을 JSON 파일로 내보내고 불러올 수 있습니다.

백업에 포함
루틴 구성 전체, 운동 이름과 순서, 완료 기록, 그리고 유튜브 링크 연결
포함되지 않음
폰 파일 연결 — 동영상 파일 자체나 파일 접근 권한은 기기를 벗어날 수 없습니다. 복원한 뒤 해당 운동만 다시 연결하면 됩니다.
파일 이름
routine-backup-YYYY-MM-DD.json
복원 시 주의
불러오기는 현재 루틴과 기록을 덮어씁니다. 필요하면 먼저 지금 상태를 내보내 두세요.
기기를 바꿀 때 백업 파일만 옮기면 루틴·기록·유튜브 영상 연결이 그대로 살아납니다. 폰에 있는 파일로 연결한 운동만 새 기기에서 다시 연결해 주면 됩니다.

11문제 해결 · 진단

상단 ☰ 메뉴 → 진단 정보 보기에서 현재 상태를 한눈에 볼 수 있고, 그대로 복사해 공유할 수 있습니다.

진단 정보에 나오는 항목

  • 보안 컨텍스트 — https가 아니면 대부분의 기능이 동작하지 않습니다
  • 홈 화면 실행 — 설치형으로 실행 중인지, 그냥 브라우저 탭인지
  • 파일 피커 — 이 기기가 ‘원본 참조’인지 ‘앱 저장소 복사’인지
  • 저장 사용량 · 루틴 / 영상 (유튜브 개수 포함)
  • 네트워크 — 오프라인이면 유튜브 영상은 재생되지 않습니다
  • 기록된 오류 — 앱이 잡아둔 오류 메시지
증상원인과 해결
‘연결 끊김 — 다시 연결하세요’원본 파일을 지웠거나 옮긴 경우입니다. 항목을 눌러 다시 연결하세요.
‘파일 접근 권한이 필요합니다’원본 참조 방식에서 권한이 만료된 것입니다. 안내 창에서 다시 연결하면 됩니다.
유튜브 영상이 검은 화면인터넷 연결을 확인하세요. 외부 재생이 막힌 영상이면 [유튜브에서 열기]로 보시면 됩니다.
[붙여넣기]가 안 됨브라우저가 클립보드 접근을 막은 경우입니다. 입력칸을 길게 눌러 직접 붙여넣으세요.
저장에 실패 / 용량 부족영상함에서 안 쓰는 영상을 지우거나, 유튜브 링크 연결로 바꿔보세요.
업데이트가 반영되지 않음진단 정보의 [캐시 비우고 새로고침]을 누르세요. 서비스 워커와 캐시를 지우고 다시 불러옵니다.
앱이 아예 안 열림오류 내용이 화면에 표시됩니다. [다시 시도]를 누르고, 계속되면 진단 정보를 복사해 두세요.
데이터가 사라지지 않게 브라우저 설정에서 ‘사이트 데이터 삭제 / 방문 기록 삭제’를 하면 루틴과 기록도 함께 지워집니다. 정기적으로 백업을 내보내 두시길 권합니다.

12기술 구조 (개발자용)

빌드 도구·프레임워크·의존성이 없는 순수 정적 파일입니다. 그대로 정적 호스팅에 올리면 동작합니다.

파일 구성

index.html
앱 셸. 상단바, 루틴 탭 줄, 본문 영역, 하단 네비게이션, 바텀시트, 재생 화면(<video> + 유튜브용 #ytbox), 토스트.
app.js
모든 로직. 상태 관리, IndexedDB 입출력, 영상 연결·재생, 렌더링, 백업.
styles.css
CSS 변수 기반 라이트/다크 테마, 세이프 에어리어 대응.
sw.js
서비스 워커. 앱 파일을 캐시하고 외부 도메인 요청은 그대로 통과시킵니다(유튜브 스트리밍 보호).
manifest.json
PWA 매니페스트 — 세로 고정, standalone 표시, 아이콘 3종.
guide.html
지금 보고 계신 이 문서.

데이터 저장

IndexedDB(workout-routine) 안에 두 개의 저장소를 씁니다.

meta
키 state 하나에 루틴·기록·UI 상태 전체를 담습니다. 변경 후 120ms 디바운스로 저장됩니다.
videos
영상 레코드. kind:'file'은 파일 핸들 또는 Blob과 캡처한 썸네일을, kind:'yt'는 영상 ID·제목·채널·시작 시간·썸네일 주소를 담습니다.

어떤 운동에서도 참조되지 않는 영상 레코드는 참조가 끊기는 시점에 자동으로 삭제됩니다.

유튜브 재생 방식

  • 주소에서 영상 ID(11자)와 시작 초를 추출합니다. 허용 도메인만 정확히 대조해 다른 사이트 주소는 걸러냅니다.
  • 제목·채널은 유튜브 oEmbed 엔드포인트로 가져옵니다(7초 타임아웃, 실패해도 연결은 진행).
  • 재생은 YouTube IFrame Player API로 앱 화면 안에 플레이어를 심습니다. 종료 이벤트를 받아 완료를 자동 기록합니다.
  • API 스크립트를 못 불러오면 일반 embed iframe으로 자동 대체합니다(이 경우 자동 완료는 동작하지 않음).
  • 재생 화면을 닫으면 플레이어를 파괴하고 iframe을 제거합니다.
개인정보 계정도 서버도 분석 도구도 없습니다. 데이터는 전부 기기 안에만 있습니다. 외부로 나가는 통신은 유튜브 링크를 쓸 때의 영상 정보 조회·썸네일·플레이어 로딩이 전부이며, 유튜브 영상을 하나도 연결하지 않으면 외부 통신은 발생하지 않습니다.
